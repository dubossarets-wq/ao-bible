# Формат модулей AO Bible (`aob-module`, версия 1)

Модуль — один JSON-файл (можно сжать gzip: `.json.gz`). Тип определяется полем `type`.
Импортёр также понимает несколько сторонних форматов (см. в конце).

## Общие поля

| Поле | Обязательно | Описание |
|---|---|---|
| `format` | да | Всегда `"aob-module"` |
| `formatVersion` | да | `1` |
| `type` | да | `"bible"`, `"commentary"`, `"dictionary"`, `"maps"` или `"crossrefs"` |
| `id` | да | Уникальный идентификатор: латиница, цифры, дефис. Модуль с тем же `id` заменяет установленный |
| `name` | да | Короткое имя для верхней панели (`"RST+"`) |
| `title` | нет | Полное название |
| `description` | нет | Описание для библиотеки |
| `language` | нет | Код языка (`ru`, `en`, `he`, `grc`) |
| `version`, `author`, `source`, `license` | нет | Метаданные. Обязательно указывайте лицензию |
| `versification` | нет | Схема нумерации стихов. Сейчас поддерживается `"synodal"` |

## Перевод Библии (`type: "bible"`)

```json
{
  "format": "aob-module", "formatVersion": 1, "type": "bible",
  "id": "rst-plus", "name": "RST+", "language": "ru", "license": "Public Domain",
  "features": { "strongs": true, "morphology": true, "headings": true },
  "books": [
    {
      "id": "Gen",
      "name": "Бытие",
      "short": "Быт.",
      "chapters": [
        ["В {начале|H7225} {сотворил|H1254 H853|TH8804} {Бог|H430} …", "…"]
      ],
      "headings": { "1:1": "Сотворение неба и земли" },
      "xrefs": { "1:1": ["Job.38.4-7", "John.1.1-3"] }
    }
  ]
}
```

- `books[].id` — OSIS-код книги (`Gen`, `Exod`, … `Matt`, … `Rev`; список в `src/core/books.json`).
  Порядок книг в массиве — порядок в навигаторе.
- `chapters` — массив глав, глава — массив строк-стихов (стих N = индекс N-1). Пустая строка означает,
  что стиха нет в переводе.
- `headings` (необязательно) — заголовки разделов перед стихом, ключ `"глава:стих"`.
- `xrefs` (необязательно) — собственные параллельные места перевода, ключ `"глава:стих"`.

### Разметка внутри стиха

| Разметка | Значение |
|---|---|
| `{текст\|H7225}` | Слово или группа слов с номером Стронга (`H` — иврит, `G` — греческий) |
| `{текст\|H1254 H853}` | Несколько номеров через пробел |
| `{текст\|H1254\|TH8804}` | Третье поле — морфологические коды через пробел |
| `‹текст›` | Слова, добавленные переводчиками (показываются курсивом) |

Без разметки строка — обычный текст. На каждое слово можно нажать: для размеченных слов словарь
получает точные номера Стронга, для остальных — приблизительное сопоставление по симфонии.

## Словарь (`type: "dictionary"`)

`dictionaryKind` определяет, как искать статью:

- `"strongs"` — ключи статей являются номерами Стронга (`H1`, `G2316`).
- `"words"` — ключи являются словами в нижнем регистре (`ё` → `е`). Поиск идёт по словоформе,
  затем по основе слова.

```json
{
  "format": "aob-module", "formatVersion": 1, "type": "dictionary", "dictionaryKind": "strongs",
  "id": "strongs-hebrew", "name": "Стронг: иврит", "language": "en",
  "entries": {
    "H3068": {
      "lemma": "יְהֹוָה", "xlit": "Yᵉhôvâh", "pron": "yeh-ho-vaw'",
      "derivation": "from H1961 (הָיָה);", "definition": "(the) self-Existent or Eternal; Jehovah, Jewish national name of God",
      "kjv": "Jehovah, the Lord."
    }
  }
}
```

Поля статьи (все необязательны): `lemma` — написание в оригинале; `xlit` — транслитерация;
`pron` — произношение; `derivation` — происхождение (номера `H…`/`G…` становятся ссылками);
`definition` — значение; `kjv` — переводы в KJV; `renderings` — `[["слово", частота], …]`;
`count` — число употреблений; `refs` — связанные стихи в OSIS (`"John.1.1"`, `"Gen.1.1-3"`);
для словарей по словам: `word` — заглавное слово, `text` — статья, `original` — оригинальное написание.

Необязательное поле модуля `wordIndex` — обратный индекс `{"словоформа": [["H3068", 2976], …]}`.
Он позволяет сопоставлять слова переводов без разметки с номерами Стронга (так работает «Симфония RST+»).

## Параллельные места (`type: "crossrefs"`)

```json
{
  "format": "aob-module", "formatVersion": 1, "type": "crossrefs",
  "id": "xrefs-rst", "name": "Параллельные места RST", "versification": "synodal",
  "refs": { "Gen.1.1": ["Job.38.4-7", "Ps.32.6", "John.1.1-3"] }
}
```

Ключ — стих в OSIS. Ссылки: `Книга.Глава.Стих`, диапазон стихов `Gen.1.1-3`, диапазон через главы `Gen.1.1-2.3`.

## Комментарий (`type: "commentary"`)

```json
{
  "format": "aob-module", "formatVersion": 1, "type": "commentary",
  "id": "lopukhin", "name": "Лоп-к", "title": "Толковая Библия Лопухина", "license": "Public Domain",
  "entries": {
    "Josh.13.33": { "title": "О уделе левитов", "text": "…" },
    "Josh.14.1-5": "Текст статьи на несколько стихов"
  }
}
```

Ключ — стих или диапазон в OSIS. Значение — строка или `{ "title", "text" }`. Пометка с `name` модуля
появляется после первого стиха диапазона; нажатие открывает статью.

## Карты (`type: "maps"`)

```json
{
  "format": "aob-module", "formatVersion": 1, "type": "maps",
  "id": "bible-maps", "name": "Карты", "license": "…",
  "maps": [
    { "id": "exodus", "title": "Исход из Египта", "description": "…", "image": "https://…/exodus.jpg", "refs": ["Exod.12.37", "Num.33.1-49"] }
  ]
}
```

`image` — адрес `https://…` или `data:image/…`. Карты открываются из меню ⋮ → «Карты».

## Каталог (`aob-catalog`)

Онлайн-каталог — JSON со списком модулей. Адреса `url`/`urlGz` указываются относительно файла каталога.

```json
{
  "format": "aob-catalog", "formatVersion": 1,
  "modules": [
    { "id": "rst-plus", "type": "bible", "name": "RST+", "title": "…", "version": "1.0", "license": "Public Domain",
      "url": "rst-plus.json", "urlGz": "rst-plus.json.gz", "size": 9958050, "sizeGz": 2379204 },
    { "id": "goetze", "type": "bible", "name": "Библия Гёце", "unavailable": true, "description": "…" }
  ]
}
```

`unavailable: true` показывает модуль в каталоге без кнопки установки.

## Сторонние форматы, которые понимает импорт

| Формат | Как распознаётся | Результат |
|---|---|---|
| Массив книг `[{ "abbrev"/"name", "chapters": [[…]] }]` | первый элемент массива содержит `chapters` | Перевод. Книги сопоставляются по названию, иначе по порядку (протестантский канон) |
| Список стихов `[{ "book", "chapter", "verse", "text" }]` или `{ "verses": [...] }` | у элементов есть `chapter`, `verse`, `text` | Перевод. `book` — OSIS-код, русское название или номер 1–66 |
| `{ "H1": {...}, "H2": {...} }` | все ключи похожи на номера Стронга | Словарь по номерам Стронга |
| `[{ "word"/"term"/"topic", "definition"/"text" }]` | у элементов есть заглавное слово и текст | Словарь по словам |
